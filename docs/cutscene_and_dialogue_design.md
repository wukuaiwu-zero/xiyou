# 《西游破劫录》过场动画演出与「20局零重复」角色台词设计书

面向抖音横版动作肉鸽的快节奏定位，整套叙事与过场系统由以下两大零外部依赖模块实现并挂载至三端（浏览器 [index.html](../index.html)、小游戏 [game.js](../game.js)、手机离线单文件包 [mobile.html](../mobile.html)）：

- **台词库与不放回抽牌引擎**：[src/config/dialogueBank.js](../src/config/dialogueBank.js)
- **像素电影过场动画与声纹导演**：[src/ui/cutsceneDirector.js](../src/ui/cutsceneDirector.js)

## 一、核心设计原则：克制体量 × 角色神韵 × 20局零重复

1. **拒绝注水与臃肿对话树**：
   - 不做《哈迪斯》式动辄两三万句的冗长站桩聊天；每句台词严格控制在 **18~38 字** 的黄金阅读窗口内，字字紧扣原著典故与局内动作机制。
   - 全库精选精修 **1,955 条** 独立不重样台词与双人小剧场（纯文本体积约 110KB），支持点击瞬间显字、单键跳过与「⚡极速行军模式（0秒锁操作）」。
2. **数学级「20局100%零重复」保证**：
   - 依托持久化 `saveData.dialogueState.seenLineIds` **全局不放回牌库** + **三级因果优先级路由**（`宿命妖王/局数里程碑/上局死因记忆/本命法相` $\rightarrow$ `十二地域/天道异象/天书质变` $\rightarrow$ `角色本色核心池`）。
   - 经 **300 组完整 20 局战役（共 6,000 局、24,000 关、105,000 次抽词）蒙特卡洛压测**：无论是五角色轮换游玩 20 局，还是**死忠单推同一名角色连打 20 局满通 80 场 Boss**，台词重复数均为 **`0`**（重复率 `0.00%`）。

| 触发节点 | 表现形态 | 20局极端触发上限（单角色满通） | 单角色独立容量 / 全库容量 | 20局重复率 |
| :--- | :--- | :--- | :--- | :--- |
| **破劫序章** | 四幕全屏分镜像素动画 (`PROLOGUE_EPIC`) | 首局 1 次（支持重温） | 4 幕分镜 + 五圣立誓群像 | `0.00%` |
| **西行出征** | 角色专属入场动作 + 宽银幕运镜 (`RUN_INTRO`) | 20 次 | **25 条/人**（共 125 条） | `0.00%` |
| **秘境行军 / 奇遇 / 觉醒** | 非阻塞左上角传音卷轴 (`WALK_BANTER`) | 40 ~ 50 次 | **60 条独白/人 + 45 组双人传音** | `0.00%` |
| **守关妖王叫阵** | Boss 殿宽银幕双幕对峙 (`BOSS_INTRO`) | 80 场 Boss | **81 难逐难专属词 + 52 条宿敌重逢词** | `0.00%` |
| **主角亮兵回敬** | 主角挥刃特效 + 纸娃娃立绘应战 (`BOSS_INTRO`) | 80 场 Boss | **120~122 条/人**（含38宿命对决词） | `0.00%` |
| **妖王伏诛判词** | 非阻塞朱砂诛邪横幅 (`BOSS_KILL`) | 80 次斩杀 | **84 条/人**（共 420 条） | `0.00%` |
| **观音甘露复活** | 九天佛光垂落重塑金身 (`REVIVE_MIRACLE`) | 20 次复活 | **22 条/人**（共 110 条） | `0.00%` |
| **九九归真 / 兵解归祠** | 金门莲桥 / 灵蕴归祠终章 (`ENDING`) | 20 次结算 | **通关 22 条 + 兵解 22 条/人** | `0.00%` |

## 二、五位主角人设声口与机制锚点

1. **孙悟空（齐天大圣 · 斗战红）**：
   - **声口**：明代章回白话鲜活猴气（“俺老孙”“孙外公”“呆子”），桀骜通透，瞧不上神佛私宠下界凑难数的把戏，重情护短。
   - **机制融合**：定海神针重砸、翻滚留毫毛金身炸盾兵、火眼金睛破幻影、身外毫毛相/定海千钧相/齐天狂雷相。
2. **唐僧（玄奘圣僧 · 妙法紫）**：
   - **声口**：摒弃传统影视剧迂腐懦弱刻板印象，塑造**“入劫圣僧 · 金刚怒目亦菩萨低眉”**的十世金蝉铁骨——对白虎岭错贬悟空怀愧，对刘洪血仇与狮驼/比丘惨案杖下雷霆不留情。
   - **机制融合**：九环锡杖穿透佛珠、金莲净世护盾震晕、甘露多一瓠、度五妖回血。
3. **猪八戒（天蓬元帅 · 金刚绿）**：
   - **声口**：市井烟火气与沙场宿将悍勇反差合一；平时算计私房金铢与大白肉包，亮出老君神冰铁九齿钉钯时尽显北极天蓬掌八万水兵之霸气。
   - **机制融合**：二段钉钯回勾拉怪、天罡旋风战车霸体吸血、饕餮厚皮爆肉包涨血上限。
4. **沙悟净（卷帘大将 · 妙法/金刚）**：
   - **声口**：拒绝沦为“大师兄说得对”背景板；还原原著灵霄碎盏贬臣、流沙河七日穿胸三百剑的冷峻孤臣与重诺铁卫，言辞简练如岳。
   - **机制融合**：月宫梭罗仙木五千斤宝杖、流沙玄水阵聚怪减速、破控增伤三成、千钧下砸开宝幢。
5. **白龙马（西海三太子敖烈 · 斗战/妙法）**：
   - **声口**：清冷孤傲的少年龙裔锐气；十万八千里卸鞍化龙，弥补宝象国化宫娥拔剑刺奎木狼未竟之憾，出枪如电、快意破空。
   - **机制融合**：独门三段踏云跳、翻滚穿敌落青雷、真龙雷霆闪瞬移刷翻滚。

## 三、六大像素过场动画与声纹演出说明

1. **【破劫序章 · 灵山碎卷】(`PROLOGUE_EPIC`)**：首次开局自动播放（亦可在主界面点左上角主标题牌匾或 `🎬 序章` 重播），含「难簿崩摧（81残页炸裂） ➔ 百魔重踞（五大妖王赤瞳现身） ➔ 五圣临渊（五师徒逐一踏落立誓） ➔ 执兵破劫（朱砂方印轰然盖落）」四幕分镜。
2. **【西行出征 · 五圣入场】(`RUN_INTRO`)**：选定开局本命法相后触发，镜头推拉配合五种角色专属像素入场特效（悟空筋斗云震棒、唐僧九品金莲法轮、八戒翠金旋风耙、悟净流沙寒渊升腾、白龙马折线惊雷化形）。
3. **【宿命交锋 · 妖王叫阵】(`BOSS_INTRO`)**：踏入 Boss 殿瞬间清空冷箭、平滑运镜对焦双方，右侧展开描金朱砂难号榜文，上演「妖王咆哮叫阵 ➔ 主角挥刃回敬」双幕宽银幕交锋，结束后赋予 `0.75s` 保护无敌帧无缝接战。
4. **【观音甘露 · 逆天重塑】(`REVIVE_MIRACLE`)**：激励视频复活成功后，九天垂落金玉光柱与上升莲瓣，角色沐浴佛光喊出翻盘宣言，结束后完整保留 `3.5s` 观音金身无敌。
5. **【九九归真 / 兵解归祠】(`VICTORY_ENDING` / `DEFEAT_EPILOGUE`)**：通关时展现破劫金门与漫天瑞彩，兵解时展现青色灵蕴飘归土地仙祠，并将本局专属结语铭刻于结算战报卡中。
6. **【16-Bit 角色声纹合成器】**：内置零音频文件的 WebAudio 声纹合成（悟空清脆方波、唐僧钟磬正弦波、八戒浑厚锯齿波、悟净沉稳低频三角波、敖烈清越雷音三角波、妖王低沉咆哮波），随打字机逐字发声并完全遵循全局静音开关。
