# 《西游破劫录》—— 抖音小游戏（2D 像素横版动作肉鸽）

一款致敬《死亡细胞》(Dead Cells) 高速动作手感与三色Build构筑、以《西游记》九九八十一难为题材的 **2D 像素横版动作 Roguelite 抖音小游戏**。

同时兼容：
- **抖音开发者工具真机/模拟器直接导入运行**（基于 `game.js` + `game.json` + `tt.*` 原生 API）
- **浏览器免构建即开即玩与联调**（直接打开 `index.html` 或启动任意静态服务）

## 二、核心《死亡细胞》肉鸽玩法特性

1. **硬核丝滑动作机制**：
   - **无敌帧翻滚取消后摇**（面对正面持盾的黑熊卫/牛魔重卫，需翻滚绕后破防！）
   - **二段跳 / 白龙马三段跳** + 土狼时间补偿
   - **单向木台下穿 & 空中千钧下砸（`下 + 跳`）**：腾空时按 `S+K` 或右侧 `下砸` 键极速坠地震晕周围群妖
   - **怪物攻击前摇红闪感叹号 `!` 预警** + 暴击顿帧（Hitstop）+ 屏幕震动 + 抖音短震动反馈
2. **三才天书卷轴构筑（对应死亡细胞三色卷轴）**：
   - **斗战天书（红）**：大幅强化普攻近战与暴虐输出
   - **妙法天书（紫）**：大幅强化神通与法宝伤害，并缩减技能冷却
   - **金刚天书（绿）**：大幅提升最大气血上限与全伤害减免
3. **六大西游法宝副武掉落**：
   - `乾坤圈`（穿透折返回旋镖）、`太阴芭蕉扇`（吹飞群妖并消除敌方弹幕）、`紫金红葫芦`（三昧真火扇形喷射）、`金刚琢`（大范围震晕+护盾）、`混天绫`（流血大范围鞭挞）、`昊天照妖镜`（贯穿激光对精英/Boss增伤）
4. **四大西游劫难关卡与守关妖王**：
   - 第一劫：**黑风山禅院** —— 守关妖王：**黑风大王·熊罴精**
   - 第二劫：**黄风岭古漠** —— 守关妖王：**黄风大圣·貂鼠精**
   - 第三劫：**白骨岭幽冥** —— 守关妖王：**白骨夫人·尸魔**
   - 第四劫：**火焰山魔窟** —— 终劫妖尊：**平天大圣·牛魔王**
5. **土地庙局外永久成长 & 章节仙缘变异词条**：击败妖王或结算时将“灵蕴”存入永久存档，升级仙根属性。

## 三、预留接口与「死亡看广告复活」接入指南

所有商业化与外部业务预留接口均集中在：
- 配置表：[src/config/sdkConfig.js](./src/config/sdkConfig.js)
- SDK 封装：[src/sdk/douyinSDK.js](./src/sdk/douyinSDK.js)

### 1. 接入真实抖音激励视频广告（死亡满血复活）
打开 `src/config/sdkConfig.js`：
```js
enableMockAd: false, // 提审上线前改为 false，自动切换为抖音官方 tt.createRewardedVideoAd
adUnitIds: {
  rewardedRevive: 'adunit-xxxxxxxxxxxxxxxx',        // 填入抖音后台激励视频广告位 ID（死亡复活）
  rewardedBonusResource: 'adunit-xxxxxxxxxxxxxxxx', // 土地庙看视频领灵蕴
  rewardedStarterWeapon: 'adunit-xxxxxxxxxxxxxxxx', // 开局仙缘法宝匣
  interstitialStageClear: 'adunit-xxxxxxxxxxxxxxxx',// 章节过渡插屏广告
  bannerHome: 'adunit-xxxxxxxxxxxxxxxx'             // 主界面 Banner 广告
}
```

### 2. 已内置的抖音平台专属能力接口
- **死亡看广告复活闭环** (`DouyinSDK.watchAdToRevive`)：自动校验 `res.isEnded`，完整观看后触发**100%满血恢复 + 25%护盾 + 3.5秒观音金身无敌 + 佛光清场冲击波**；若中途关闭广告，保留在复活界面提示玩家未完播，不会误扣复活次数。
- **抖音侧边栏复访有礼** (`DouyinSDK.navigateOrClaimSidebar`)：已对接 `tt.checkScene` 与 `tt.navigateToScene({ scene: 'sidebar' })`（满足抖音平台侧边栏必接规范）。
- **抖音游戏录屏与一键发视频** (`DouyinSDK.startRecord` / `stopRecord` / `shareGameOrVideo`)：对接 `tt.getGameRecorderManager()` 与 `tt.shareAppMessage({ channel: 'video' })`。
- **外部后端钩子** (`SDK_CONFIG.externalHooks`)：预留 `onBeforeGrantAdReward`（服务端防刷校验）、`onPlayerRevived`、`onRunFinished`（排行榜上报）、`onTrackEvent`（自定义BI埋点）。

## 四、运行方式

### 方式 A：抖音开发者工具运行
1. 打开 **抖音开发者工具** -> 选择 **小游戏** -> **导入项目**。
2. 目录选择本项目根目录，填入您的测试 AppID（或使用游客/测试号），确保屏幕方向为横屏 (`landscape`) 即可直接编译预览。

### 方式 B：浏览器即时预览调试
直接双击打开 `index.html`，或在项目目录下执行：
```bash
python3 -m http.server 8080
```
浏览器访问 `http://localhost:8080` 即可体验（页面底部附带【🎬 测试死亡复活广告】与【👹 瞬移打Boss】联调按钮）。
